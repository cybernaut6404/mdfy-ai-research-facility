# Deviations from Pre-Registration / Exploration Plan — DEMO

> **⚠ DEMO.** Included for structural completeness.

This is a Tier-M publication and did not require a pre-registration. There is no plan from which to deviate. This file is retained so that the publication folder has the same shape as Tier-C and Tier-E folders, which require a Deviations document whether or not deviations occurred.

For real Tier-C and Tier-E publications, this file documents, in order:

1. Each pre-registered analysis that was conducted as planned.
2. Each pre-registered analysis that was modified or omitted, with the rationale.
3. Each analysis that appears in the manuscript and was not in the pre-registration, with explicit labelling as exploratory/additional.
4. Each conclusion that has shifted as a result of deviations.

Undisclosed deviations are a serious breach of unit standards (Charter §8).
