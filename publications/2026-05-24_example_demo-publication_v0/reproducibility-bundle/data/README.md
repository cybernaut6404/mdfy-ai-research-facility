# Data — DEMO

> **⚠ DEMO.** This DEMO publication uses no data. The directory exists for structural-compliance purposes.

For real publications, this directory contains either:

- **The raw data itself,** if it can be redistributed under the publication's license, along with cryptographic checksums (SHA-256) of every file in `CHECKSUMS.txt`; or
- **A documented access procedure** if the data cannot be redistributed, plus checksums of the files used, plus any preprocessing scripts.

A `LICENSE.md` in this directory specifies the data license. Where third-party data is used, the more-restrictive license terms govern, and this `README.md` documents which is which.

For derived/processed data: include both the raw data (or pointer) and a script that reproduces the derived form, so that no derived figure depends on a manual step.

See `STANDARDS.md` "Reproducibility Bundle — Data" section for the canonical checklist.
