# Correspondence — DEMO

> **⚠ DEMO.** This directory is empty for the DEMO. For real publications it holds: editor correspondence, response-to-reviewers documents, decision letters, and any preprint-server / venue communications relevant to the publication record.

Naming conventions for this directory:

- `YYYY-MM-DD_to-editor_subject.md` — emails or letters the unit sent.
- `YYYY-MM-DD_from-editor_subject.md` — correspondence received.
- `YYYY-MM-DD_response-to-reviewers.md` — point-by-point responses.

Sensitive content (personal addresses, unrelated material from a thread) is redacted before commit; redactions are noted in `REDACTIONS.md` with rationale.
