_Generated by experiments/d4-fader-intervention/analyse_multiturn.py — local only, no API._

Pairs analysed: 160 (20 starters × 8 turns).

## Method

Counts per response of: response length (words), action-direct markers (short
imperatives, KPI/budget/measurement language, action verbs), relational-process
markers (empathy, listening, conversation, gentle/honour, emotional language),
and refusal markers. Patterns in source.

Hypothesis: rick > coach on action-direct, coach > rick on relational. If lex
diffs go in the predicted direction, the substrate produces a measurable
behavioural shift even when the LLM judge ties.

## Interpretation

If Δ Action > 0 and Δ Relational < 0, the substrate produced the predicted
lex-level shift even when single-shot LLM-judge ties. Hypothesis-aligned but
below the threshold of LLM-perceptible discriminability.

If Δ Action ≈ 0 and Δ Relational ≈ 0, the substrate is genuinely not
differentiating outputs at the surface lex level — the failure is real,
not just judge limitation.

If signs are reversed (Δ Action < 0, Δ Relational > 0), composition is
actively producing the wrong direction — composite vector geometry is
interfering with the per-channel signal.
